backtest_straddle.py
====================
Point-in-time backtest of the straddle screener over completed monthly expiries.

    python backtest_straddle.py --dte 25 --paths 8000
    python backtest_straddle.py --dte 25 --stop-k 1.5 --out bt_stop15.csv
    python backtest_straddle.py --dte 25 --model ewma --out bt_ewma.csv

What it does, and the guardrail on each step
--------------------------------------------

UNIVERSE is reconstructed from exposure_eod AS OF the entry date, never from
today's watchlist. Using the current F&O list would be survivorship bias: names
enter and leave F&O eligibility and the ban list constantly.

EVERY FEATURE is bounded by the entry date. No expanding windows computed over
the full table, which is the classic silent look-ahead in this kind of script.

THE REALISED PATH IS WALKED DAILY from cash_eod closes, so the same exit rule
the simulator applies to synthetic paths is applied to the actual one. Comparing
a stop-rule prediction against a hold-to-expiry outcome makes the calibration
meaningless.

SETTLEMENT uses the cash_eod close on expiry day. NSE equity bhavcopy CLOSE is
the volume-weighted average of the last 30 minutes, which is the settlement
basis -- not the last trade.

VRP_Z is built on ln(ATM_IV / HV20) rather than ln(ATM_IV / RV_forecast). Two
reasons: it is the published Goyal-Saretto form and therefore the benchmark the
forecast-based version has to beat, and it avoids refitting GARCH ~150 times per
symbol to construct the history. The forecast-based ratio is recorded alongside
as vrp_ratio so the two can be compared directly.

MODEL AVAILABILITY. bhav.cash_eod begins 2025-12-01, so only expiries from
June 2026 have the >=120 observations a GARCH(1,1)-t fit needs; earlier ones
fall back to EWMA. The model used is recorded per row -- do NOT pool GARCH and
EWMA rows when judging forecast quality. Backfilling older bhavcopy archives is
the single highest-value fix available to this backtest.

WHAT THE OUTPUT CAN AND CANNOT SETTLE. Seven cross-sections, all loading on the
same index vol factor, cannot fit weights or confirm a small IC. Per-expiry IC
standard error is ~0.09 at n=120 before any allowance for cross-sectional
dependence. Read this as a smoke test for gross failure and for miscalibration,
not as validation.
